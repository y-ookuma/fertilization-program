# 野菜施肥設計計算アプリ

土壌分析値と作物ライブラリから、10aあたりの目標NPK量・不足量・石灰／堆肥のめやすを自動計算し、結果をPNG画像として保存できるWebアプリです。サーバー不要、ブラウザだけで完結します。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面構造（入力フォーム・結果表示・手順書モーダル） |
| `style.css` | デザイン（配色・カード・NPKバーなど） |
| `app.js` | 作物ライブラリ・計算ロジック・保存/復元・PNG出力 |
| `crops.json` | 30品目の作物データ（参照用。実際の計算は`app.js`内に埋め込まれた同内容のデータを使用） |
| `README.md` | このファイル |

`index.html` をブラウザで開くだけで動作します（インターネット接続はGoogleフォントとPNG出力用ライブラリ[html2canvas]の読み込みにのみ必要です）。

---

## 使い方

1. **栽培作物の選択**
   プルダウンから作物を選ぶと、その作物の基準養分吸収量・標準元肥比率がライブラリから読み込まれます。

2. **土壌分析結果の入力**
   pH、EC、CaO（石灰）、MgO（苦土）、K2O（加里）、トルオーグ燐酸、CEC、塩基飽和度、石灰/苦土比、苦土/加里比を入力します。未入力の項目は計算上0または「未入力」として扱われます。

3. **施肥設計を計算する**
   ボタンを押すと以下が表示されます。
   - 作物名（絵文字付きバッジ）
   - 窒素・リン酸・加里それぞれの「目標量」「土壌残存量換算」「不足量」をバー付きカードで表示
   - 石灰資材のめやす（pHと石灰/苦土比から算出）
   - 堆肥のめやす（作物のカテゴリー別）

4. **結果をPNG保存**
   結果カード右上の「🖼️ 結果をPNG保存」ボタンで、作物名・NPK・石灰・堆肥のめやすをまとめた画像をダウンロードできます。

5. **パラメータの保存・復元**
   - 「💾 パラメータを保存」：ファイル名を指定して入力内容を`.json`ファイルとしてダウンロードします（拡張子は自動付与）。
   - 「🔁 パラメータを復元」：保存済みの`.json`ファイルを選択して読み込みます。ブラウザやPCが変わってもファイルさえあれば復元できます。

## 計算式の詳細

このアプリの計算はすべて `app.js` 内で完結しています。以下は実際に使われている式です。

### 1. 目標成分量（目標吸収量ベース）

作物ライブラリの「養分吸収量」に「標準元肥比率」を掛けた値を、その作物の目標施肥量（10aあたり）とします。

```
目標N   = 養分吸収量N   × 標準元肥比率N
目標P2O5 = 養分吸収量P2O5 × 標準元肥比率P2O5
目標K2O  = 養分吸収量K2O  × 標準元肥比率K2O
```

- **養分吸収量**：作物が収穫までに吸収する総量のめやす（品目ごとにライブラリで定義）。
- **標準元肥比率**：吸収量のうち「元肥（植付け前に施す分）」でまかなう割合。追肥中心の作物ほど小さく（例：トマト0.3）、生育期間が短く一度に施肥する葉物ほど大きく（例：ホウレンソウ0.7）設定しています。

### 2. 土壌残存量換算（簡易ロジック）

入力された土壌分析値から、すでに土壌中にある養分を「元肥として節約できる量」に換算します。

```
残存N   = 25 × 0.2       ※窒素は簡易的に土壌診断値を25 mg/100g相当とみなす仮定値
残存P2O5 = 入力トルオーグ燐酸 × 0.15
残存K2O  = 入力K2O          × 0.15
```

> ⚠️ 窒素は硝酸態窒素などの実測値を入力する項目がないため、暫定的に固定値（25）を使っています。地域の土壌診断基準に硝酸態窒素の実測フローがある場合は、その値をここに差し替えることを想定しています。
> 係数（0.2 / 0.15）はmg/100gをkg/10aの元肥節約量に大まかに換算するための簡易係数で、土性（砂土・壌土・粘土）や作土深によって変わります。実運用では地域・JAの施肥基準にある換算係数に置き換えてください。

### 3. 不足量（設計施肥量）

```
不足N   = max(0, 目標N   − 残存N)
不足P2O5 = max(0, 目標P2O5 − 残存P2O5)
不足K2O  = max(0, 目標K2O  − 残存K2O)
```

土壌にすでに十分量がある場合はマイナスにならないよう0未満は切り捨て、カード上に「✅ 目標量に到達しています」と表示します。

### 4. 石灰資材のめやす

**pHからの必要量算出**

```
目安pH = 作物ごとのtargetPh（未設定作物は既定値 6.3。ジャガイモのみ 5.8）
必要な苦土石灰量(kg/10a) = round( (目安pH − 入力pH) × 120 )   ※入力pH < 目安pHの場合のみ
```

- 係数「120」は、「pHを0.1上げるのに苦土石灰（ドロマイト）が10aあたり約12kg必要」という一般的な目安（pH1.0あたり約120kg）を採用した簡易値です。実際の必要量は土性・CEC・作土深によって数十%単位で変動します。
- 入力pHが目安pH以上の場合は「石灰質資材の追加は控えめで大丈夫」というメッセージになります。

**石灰/苦土比からのバランス判定**

```
石灰/苦土比 > 8  → 苦土（マグネシウム）が相対的に不足気味 → 苦土石灰（ドロマイト）を推奨
石灰/苦土比 < 3  → 苦土に対して石灰が少なめ → 炭酸カルシウムなど苦土を含まない資材を推奨
3 ≦ 比 ≦ 8     → バランス良好
```

一般的に石灰/苦土比は5:1前後が目安とされていることを踏まえた簡易しきい値です。

### 5. 堆肥のめやす（作物カテゴリー別）

各作物には次の7カテゴリーのいずれかが割り当てられており、カテゴリーごとに固定の目安コメントを表示します（土壌分析値は使用しません）。

| カテゴリー | 該当作物の例 | めやす |
|---|---|---|
| 果菜類 (fruit) | キュウリ、トマト、ナス、スイカなど | 完熟堆肥 2〜3 t/10a、植付け3週間以上前 |
| 葉菜類 (leafy) | キャベツ、ハクサイ、ホウレンソウなど | 堆肥 1.5〜2 t/10a、窒素過多に注意 |
| 根菜類 (root) | ダイコン、ニンジン | 完熟堆肥 1.5〜2 t/10a、未熟堆肥は又根の原因に |
| りん茎類 (bulb) | タマネギ、ニンニク、ネギ | 完熟堆肥 1.5〜2 t/10a、よく耕うん |
| いも類 (tuber) | ジャガイモ、サツマイモ、サトイモ、ショウガ | 完熟堆肥 1.5〜2 t/10a、窒素過多を回避 |
| 豆類 (legume) | エダマメ、インゲンマメ | 堆肥 1〜1.5 t/10a（根粒菌による窒素供給を考慮し控えめ） |
| 多年生 (perennial) | アスパラガス | 定植・株分け時に3〜4 t/10a、以降は毎年株元に補う |

> ⚠️ 石灰・堆肥のめやすは、いずれも一般的な栽培指針をもとにした簡易的な参考値です。実際の施用量は、土壌診断結果・地域やJAの施肥基準・圃場の履歴に応じて必ず調整してください。

## Q&A

**Q1. 計算結果はそのまま実際の施肥設計に使えますか？**
A. いいえ。窒素残存量が固定値（25 mg/100g相当）である点、石灰・堆肥の係数がいずれも簡易的な一般値である点から、本アプリはあくまで「試算・学習用のたたき台」です。実際の施肥設計は、お使いの地域・JAの施肥基準や土壌診断結果に基づいて専門家に確認してください。

**Q2. 窒素の土壌残存量に実測値を反映できますか？**
A. 現状のフォームには硝酸態窒素などの入力欄がないため、`app.js`内の `soilN = 25` の固定値が使われます。実測値を反映したい場合は、`soilN` を入力フィールドから取得するように`app.js`を修正してください（他の項目と同様にフォームを追加する形になります）。

**Q3. 石灰の必要量の計算に使っている「120」という係数の根拠は？**
A. 「pHを0.1上げるのに苦土石灰が10aあたり約10〜15kg必要」という一般的な栽培指針を参考にした簡易値（pH1.0あたり約120kg）です。実際の必要量は土性・CEC・作土深によって変わるため、目安として利用し、詳細は土壌診断機関や普及指導センターの基準値に置き換えることをおすすめします。

**Q4. 堆肥の量が作物ごとに決まっていて、圃場の腐植量などが反映されていないのはなぜですか？**
A. 現バージョンでは堆肥のめやすを「作物カテゴリー」だけで簡易的に出しています。腐植含量や有機物診断値を反映させたい場合は、対応する入力欄と計算式を追加する拡張が必要です。

**Q5. パラメータの保存・復元はサーバーに送信されますか？**
A. されません。保存はブラウザ内で`.json`ファイルを生成してダウンロードするだけ、復元は選択したファイルをブラウザ内で読み込むだけで、外部通信は発生しません（PNG出力機能とフォント読み込みのみ、初回にCDNへアクセスします）。

**Q6. オフライン環境でも使えますか？**
A. フォームの入力・計算・PNG出力用ライブラリやフォントが一度キャッシュされていれば、基本機能はオフラインでも動作します。ただし初回読み込み時はGoogleフォント（Zen Maru Gothic / Noto Sans JP）と html2canvas ライブラリの取得にインターネット接続が必要です。

**Q7. 保存したファイルを別のPCで復元できますか？**
A. できます。保存される`.json`ファイルには作物ID・土壌分析値がすべて含まれているため、そのファイルを別のPC・別のブラウザで開いた本アプリの「パラメータを復元」から読み込めば、同じ内容が復元されます。

**Q8. 対応している作物を増やしたい場合は？**
A. `app.js`内の`fertilizerLibrary.crops`配列（および参考データの`crops.json`）に、同じ形式（id・name・emoji・category・nutrient_absorption_kg_10a・standard_basal_ratio、必要ならtargetPh）でオブジェクトを追加してください。

**Q9. スマートフォンでも使えますか？**
A. レスポンシブデザインに対応しており、スマートフォンやタブレットのブラウザでも入力・計算・PNG保存が可能です。

**Q10. PNG画像に保存されるのはどの範囲ですか？**
A. 「作物名（大きな絵文字付き）」「NPKカード」「石灰・堆肥のめやすカード」「注記」までを含む結果エリア全体が1枚の画像として書き出されます。入力フォームや操作ボタンは含まれません。
