# 施肥設計計算アプリ

土壌分析値から、**埼玉県「主要農作物施肥基準」（令和7年1月）の方法**に沿って基肥（元肥）の N・P2O5・K2O と、石灰(CaO)・苦土(MgO)の補正量を計算し、使う肥料の袋数まで求めて施肥設計書（PNG/PDF）にまとめるWebアプリです。サーバー不要、ブラウザだけで動きます。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面構造（①土壌分析 → ②分析結果と肥料投入量 → ③施肥設計書 の3ステップ、手順書・READMEモーダル） |
| `style.css` | デザイン |
| `saitama-data.js` | **基準データ（出典つき）**：作物別施肥基準、土壌タイプ（表5）、CEC別適正塩基（表8）、減肥の区分、堆肥の成分・肥効率など |
| `calc.js` | **計算ロジック**（画面に依存しない関数だけ。テスト対象） |
| `app.js` | 画面の操作・表示、保存/復元、肥料CSV読み込み、PNG/PDF出力 |
| `crops.json` | 作物データの参照用コピー（アプリは `saitama-data.js` を使用） |
| `tests/` | 計算ロジックのテスト（出典の計算例を期待値にしている） |
| `肥料CSV/` | サンプルの肥料一覧CSV |

`index.html` をブラウザで開くだけで動作します。インターネット接続は、Googleフォント、PNG/PDF出力用ライブラリ（html2canvas・jsPDF）、README表示用のMarkdownパーサ（marked.js）の読み込みにのみ必要です。

> ⚠️ README.md はアプリ内の「📄 README」ボタンから `fetch` で読み込んでいます。`index.html` をファイルとして直接開く（`file://`）と読み込めない場合があります。その場合は `python -m http.server` などで `http://` として開いてください。

## 使い方（3ステップ）

画面上部の「① 土壌分析 → ② 分析結果と肥料投入量 → ③ 施肥設計書」のタブで進めます。②・③は、手前のステップで計算するまで選べません。**①の入力を変えると②・③は再びロックされ、②の入力を変えると③がロックされます**（古い計算結果のまま設計書が作られるのを防ぐため）。

### ① 土壌分析

1. **栽培作物の選択**：作物と作型を選ぶと、県基準の基肥量・合計施肥量と出典ページが表示されます。県基準にない作物は「参考値」グループにあります（出典未確認）。他県の基準を使うときは「✏️ 作物・基肥量を直接入力する」を選び、基肥 N・P2O5・K2O を入力します。
2. **土壌のタイプと作土**：土壌のタイプを選ぶと、仮比重とCECの代表値（県基準 表5）が入ります。作土深は既定15cm。実測値があれば書き換えてください。
3. **土壌分析結果入力**：pH、EC、交換性石灰・苦土・加里、有効態リン酸（トルオーグ法）、CEC、塩基飽和度、石灰/苦土比・苦土/加里比（当量比）、硝酸態窒素、アンモニア態窒素。**未測定の項目は空欄のまま**にします（0ではなく未測定として扱い、その項目による減肥・補正はしません）。
4. **堆肥（任意）**：家畜ふん堆肥の種類・施用量(t/10a)・水分(%)を入れると、有効成分を基肥から差し引きます。
5. 「🌾 施肥計算をする」で②へ進みます。

### ② 分析結果と肥料投入量

1. N・P・K は「**施肥基準 − 土壌による減肥 − 堆肥の有効成分 ＝ 設計量**」、石灰・苦土は「**CEC別適正範囲の下限までの不足量**」がカードで表示されます。土壌の換算条件・窒素の減肥・堆肥・石灰苦土の補正の説明も表示されます。
2. **⑤ 圃場**：圃場名と面積（㎡・a・ha）を入力します。未入力は10a。
3. **⑥ 使用する肥料（最大8種類）**：成分(%)・1袋の重量・今回投入量を入力し「🧮 投入量を計算する」で、設計量と投入量の過不足・袋数を表示します。「📂 肥料一覧CSVを読み込む」で肥料名から成分を自動入力できます。
4. **特筆事項（任意・400文字）** を書いて「✅ 施肥設計完了」を押すと、最新の入力で計算し直して③を作ります。

### ③ 施肥設計書

圃場名・作物・面積、土壌分析結果（県基準の適正範囲との比較）、**計算条件**（土壌タイプ・作土深・仮比重・CECの出どころ・窒素の計算）、設計量の内訳、設計量と投入量、使用する肥料、堆肥、石灰・苦土の補正、特筆事項をまとめます。「🖼️ 結果をPNG保存」「📄 結果をPDF保存」でA4レイアウトで保存できます（右下にライセンス表記。PDFは複数ページに自動分割）。

### その他のボタン

- **🌱 作物別施肥基準一覧**：登録している作物・作型の基肥、合計（基肥＋追肥）、出典ページの一覧。
- **💾 パラメータを保存 / 🔁 パラメータを復元**：作物・土壌・堆肥・面積・肥料・特筆事項を `.json` で保存・復元します。旧バージョンで保存したファイルも読み込めます（作物は対応する作型に読み替え。例：キュウリ（ハウス栽培）→ きゅうり（促成））。外部には送信しません。
- **📁 サンプル肥料一覧CSV**：GitHubの[肥料CSVフォルダ](https://github.com/y-ookuma/fertilization-program/tree/main/%E8%82%A5%E6%96%99CSV)を開きます。

### 1. 施肥基準（基肥量）

作物・作型ごとの基肥 N・P2O5・K2O は **[埼玉R7] 野菜編 p.46〜75・水稲 p.38 の施肥基準表の「基肥」の値**をそのまま使います（`saitama-data.js` の `crops`。各作物に出典ページを記録）。水稲の値は「速効性化学合成肥料を使用した場合の数値」で、県基準では原則として記載の施肥量を上限としています。

- 基肥のない作型（ねぎ、トマト長期越冬（養液土耕）、やまといも、葉しょうが）は基肥0kgです。
- 県基準にない作物（ピーマン、スイカ、ジャガイモ など14品目）は、旧ライブラリの「養分吸収量×標準元肥比率」による**参考値（出典未確認）**として残しています。
- 他県の基準を使う場合は「作物・基肥量を直接入力する」で基肥量を入力してください。減肥の計算は同じ方法で行います。

### 2. mg/100g → kg/10a の換算（[青森] p.35・p.39、[埼玉R7] p.12）

```
換算係数 = 作土深(cm) ÷ 10 × 仮比重
（10aの作土の重さ = 1,000㎡ × 作土深(m) × 仮比重）
```

例：作土深15cm・仮比重0.7（黒ボク土）→ 1.05、仮比重1.0 → 1.5（[青森] 表25の注と一致）。

土壌タイプを選ぶと、仮比重とCECの代表値が入ります（[埼玉R7] 表5。表に幅がある場合は**中央値を代表値にした**のはアプリの取り扱いです）。表5にない砂質土の仮比重1.1は [青森] p.38 の目安です。CECが空欄のときは土壌タイプの代表値を使います（[埼玉R7] p.9「表5の土壌タイプの平均値を参考に推定してもよい」）。

### 3. 窒素（[埼玉R7] 技術編 p.12）

```
無機態窒素 = 硝酸態窒素 + アンモニア態窒素   (mg/100g)
土壌から差し引く窒素(kg/10a) = max(0, 無機態窒素 − 3) × 換算係数
設計量N = max(0, 基肥N − 土壌から差し引く窒素 − 堆肥の有効N)
```

県基準の診断例（作土深15cm・仮比重1.1・無機態窒素5mg → 3.3kg）と一致することをテストで確認しています。

**硝酸態窒素が未入力でECがある場合**は [藤原2008] の式で推定します（負の値は0）。

| 土壌 | 硝酸態窒素(mg/100g) |
|---|---|
| 黒ボク土 | 38 × EC − 10 |
| 沖積土・洪積土 | 44 × EC − 15 |
| 砂質土 | 29 × EC − 5 |

硝酸態窒素・ECとも未入力の場合は、**窒素を差し引きません**（以前の版のように仮のEC値で差し引くことはしません）。施設土壌では硝酸以外の塩類（硫酸根など）もECを上げるため、ECからの推定は誤差が大きくなります。

### 4. リン酸（[埼玉R7] 技術編 p.13）

| 有効態リン酸（トルオーグ法, mg/100g） | 施肥基準のリン酸から |
|---|---|
| 80未満 | 減肥しない |
| 80〜100未満 | 20%減肥 |
| 100〜200未満 | 40%減肥 |
| 200〜300未満 | 60%減肥 |
| 300以上 | 施用しない |

```
設計量P2O5 = max(0, 基肥P2O5 × (1 − 減肥率) − 堆肥の有効P2O5)
```

例：基準18kg・150mg → 10.8kg（県基準の診断例と一致）。

### 5. 加里（[埼玉R7] 技術編 p.13・表8）

表8（CEC別の適正な交換性加里の範囲）を使います。

```
上限+10mg を超える分：差し引く量 = (分析値 − (上限 + 10)) × 換算係数
下限−5mg を下回る分：増肥する量 = ((下限 − 5) − 分析値) × 換算係数
設計量K2O = max(0, 基肥K2O − 差し引く量 + 増肥する量 − 堆肥の有効K2O)
```

例：CEC16・作土深10cm・仮比重1・交換性カリ50mg・基準12kg → 上限34mg → 12 −(50 − 44) = **6kg**（県基準の診断例と一致）。

- 表8はCEC 10〜40me を5me刻みで示しています。アプリは**最も近いCECの行**を使います（等距離なら小さい方。範囲外は端の行）。県基準の診断例（CEC16 → CEC15の行の上限34mg）と同じ扱いです。
- 県基準の診断例は作土深10cm・仮比重1（換算係数1.0）のため mg と kg が同じ値になっています。アプリは作土深・仮比重に応じて換算係数を掛けています（**解釈**）。
- CECが不明な場合は加里の加減をしません。

### 6. 石灰・苦土（[埼玉R7] 表8、[青森] p.35）

目標は作物ではなく土壌のCECで決まります。表8のCEC別の適正範囲の**下限までの不足量**を計算します。

```
必要量(kg/10a) = max(0, 適正範囲の下限 − 分析値) × 換算係数
```

計算式は [青森] p.35 の「不足石灰量を算出する方法」と同じです（例：235mg→300mg・作土10cm・仮比重0.7 → CaO 45.5kg/10a。炭酸カルシウム(CaO 53%)なら85.8kg）。

- **下限まで**としたのはアプリの取り扱いです（県基準は「塩基飽和度が適正範囲に収まるよう苦土及び石灰量を決定する」としています）。
- 石灰/苦土比・苦土/加里比（当量比）、塩基飽和度が表8の範囲を外れる場合や、pHが6.5を超える場合は注意を表示します。
- 当量比・塩基飽和度が未入力のときは、分析値から計算します（[埼玉R7] p.9：CaO 28.04、MgO 20.15、K2O 47.1 mg/me）。

```
石灰/苦土比 = (CaO/28.04) ÷ (MgO/20.15)
苦土/加里比 = (MgO/20.15) ÷ (K2O/47.1)
塩基飽和度(%) = (CaO/28.04 + MgO/20.15 + K2O/47.1) ÷ CEC × 100
```

### 7. 堆肥（[埼玉R7] 技術編 表17・18、[長野] 表1）

| 堆肥（水分50%現物） | N % | P2O5 % | K2O % | 肥効率 N / P2O5 / K2O (%) |
|---|---|---|---|---|
| 牛ふん | 1.05 | 1.03 | 1.10 | 20 / 60 / 90 |
| 豚ぷん | 1.43 | 2.06 | 1.12 | 40 / 60 / 90 |
| 鶏ふん | 1.45 | 2.57 | 1.34 | 50 / 70 / 90 |
| おが屑混合 牛ふん | 0.83 | 0.80 | 0.85 | 10 / 50 / 90 |
| おが屑混合 豚ぷん | 1.06 | 1.69 | 0.92 | 20 / 50 / 90 |
| おが屑混合 鶏ふん | 0.97 | 2.05 | 1.07 | 25 / 60 / 90 |

バーク堆肥・もみがら堆肥は埼玉県の基準に成分・肥効率がないため、[長野] 表1の値を使います。成分は各資材全体の平均の**現物%**で、水分の基準が示されていないため、水分による補正はしません。

| 堆肥（現物） | N % | P2O5 % | K2O % | 肥効率 N / P2O5 / K2O (%) |
|---|---|---|---|---|
| バーク堆肥 | 0.3 | 0.1 | 0.1 | 10 / 50 / 70 |
| もみがら堆肥 | 0.5 | 0.6 | 0.5 | 10 / 50 / 80 |

```
成分(現物%) = 表18の成分 × (100 − 水分) ÷ 50    （家畜ふん堆肥のみ）
有効成分(kg/10a) = 施用量(t) × 1000 × 成分(%)/100 × 肥効率(%)/100
```

水分70%の堆肥は水分50%の約1.68倍量で同じ成分になります（[埼玉R7] 表20と一致）。分析値がある堆肥は「成分を直接入力する」で現物の成分と肥効率を入力します。堆肥の石灰・苦土は差し引いていません（県基準に肥効率がないため）。

土壌・堆肥からの供給が基準を上回る場合は設計量0kgとし、超過量を表示します（堆肥の量を減らす目安。[青森] p.235 の注意事項と同じ考え方）。

作物ごとの「良質な堆肥」の目安量は、[埼玉R7] 野菜編の各作物の「土づくり」の記載です（例：きゅうり3t/10a、えだまめ1t/10a）。水稲は技術編 表19の家畜ふん堆肥の目安を表示します。

### 8. 面積の換算

```
面積スケール = 圃場面積(㎡) ÷ 1,000
実面積の量 = 10aあたりの量 × 面積スケール
```

### 9. 使用する肥料・袋数

```
投入成分 = 今回投入量 × 成分(%) ÷ 100
袋数 = ceil(今回投入量 ÷ 1袋の重量)
```

8種類の合計を設計量（面積換算後）と比べて過不足を表示します。

### 10. 土壌分析結果のバッジ（③施肥設計書）

各項目を適正範囲と比べ、範囲内なら「✓ 適正」、下回れば「↓ 下限まで ○○」、上回れば「↑ 上限を ○○ 超過」と表示します。

| 項目 | 適正範囲 | 出典 |
|---|---|---|
| pH(H2O) | 6.0〜6.5 | [埼玉R7] 表7（水田・普通畑） |
| EC (mS/cm) | 野菜：土壌・作物別（例：黒ボク土の果菜類0.3〜0.8、葉・根菜類0.2〜0.6）／水稲：0.2以下 | [藤原2008]／[埼玉R7] 表7 |
| 交換性石灰・苦土・加里、塩基飽和度、石灰/苦土比、苦土/加里比 | CEC別の範囲 | [埼玉R7] 表8 |
| 有効態リン酸 | 畑：10〜75mg（黒ボク土・多湿黒ボク土は10〜100mg）／水田：10mg以上 | [埼玉R7] 表7 |
| CEC | 12me以上（黒ボク土・多湿黒ボク土・黒泥土・泥炭土などは15me以上） | [埼玉R7] 表7 |

硝酸態窒素は範囲ではなく、差し引いた窒素量（kg/10a）を表示します。

### 11. 肥料一覧CSVの読み込み

「📂 肥料一覧CSVを読み込む」でCSVを読み込むと、各肥料行の「CSVから選択」で肥料名を選ぶだけで、N・P2O5・K2O・石灰・苦土・1袋の重量が入ります（選び直すと、その行はいったん空欄に戻してから入力）。

- 文字コードは UTF-8・Shift_JIS（CP932）を自動判定します。
- 見出し行の列名は次のいずれかなら自動で認識します（全角・半角や記号の違いは無視）。

| 項目 | 認識する見出しの例 |
| --- | --- |
| 区分（任意） | 区分、分類、category |
| 肥料名（必須） | 名称、肥料名、品名、name |
| N (%) | N、窒素 |
| P2O5 (%) | P、P2O5、りん酸 |
| K2O (%) | K、K2O、加里、カリ |
| 石灰 CaO (%) | 石灰、CaO |
| 苦土 MgO (%) | 苦土、MgO |
| 1袋の重量(kg)（任意） | 1袋の重量、袋重量、重量、重量(kg) |

- **セル全体が数値のものだけ**を読み取ります（末尾の%は可）。「6〜8」のような範囲表記や「マンガン0.5%」のような文字列は空欄として扱います。
- サンプル「JAさいたま肥料一覧.csv」には1袋の重量の列がないため、重量は手入力してください。

## Q&A

**Q1. 計算結果をそのまま施肥に使えますか？**
A. 計算方法は埼玉県の施肥基準に沿っていますが、青森県のマニュアル（p.232）にもあるとおり「減肥した場合は、作物の生育状況を確認しながら、生育が劣る場合は追肥等による調整が必要」です。前作や圃場の履歴も踏まえて、JA・普及指導員と確認してください。埼玉県以外では、お住まいの都道府県の施肥基準の値を「直接入力」で使ってください。

**Q2. 以前の版と比べて何が変わりましたか？**
A. 主な変更点は次のとおりです。
- 作物の基肥量を「養分吸収量×標準元肥比率」から、県基準の表の値に変えました。
- 分析値の換算を、固定の0.15から「作土深÷10×仮比重」に変えました（黒ボク土・作土15cmで1.05〜1.3程度。以前は約7〜10倍小さく見積もっていました）。
- リン酸・加里は、県基準の減肥方法に変えました。
- 石灰・苦土の目標を、固定値（300・40mg）からCEC別の適正範囲に変えました。
- ECから窒素を推定する係数（以前はEC×80）を、土壌別の式に変えました。
- 未測定の項目を0として扱っていたのを、「未測定＝差し引かない」に変えました。

**Q3. 窒素の分析値がないときは？**
A. ECがあれば土壌別の式で推定します。どちらもなければ窒素は差し引きません。前作の残肥が多そうな場合は硝酸態窒素の測定をおすすめします。

**Q4. 石灰/苦土比・苦土/加里比は重量比と当量比のどちらを入れればよいですか？**
A. 当量比です（県基準 表8は当量比）。報告書が重量比の場合や、比の記載がない場合は空欄にしてください。CaO・MgO・K2Oの分析値から当量比を計算します。

**Q5. CECが分からないときは？**
A. 土壌のタイプを選んでおけば、その代表値（県基準 表5）で計算します。砂質土・その他の土壌では代表値がないため、CECを入力しない場合は加里の加減と石灰・苦土の補正を計算しません。

**Q6. 堆肥の成分が表と違うときは？**
A. 「成分を直接入力する」を選び、分析値（現物%）と肥効率を入力してください。

**Q7. 県基準にない作物は？**
A. 「参考値」グループの作物は旧版の値（出典未確認）です。できるだけ「作物・基肥量を直接入力する」で、根拠のある基準値を入力してください。

**Q8. PNG・PDFはどの範囲が保存されますか？**
A. ③施肥設計書の全体を、A4の幅（約210mm、200dpi相当）で出力します。PNGは1枚の画像（長い場合は縦長）、PDFはA4ページに自動分割します。右下にライセンス表記が入ります。

**Q9. データはサーバーに送信されますか？**
A. されません。保存・復元・CSV読み込みはすべてブラウザ内で行います（外部通信はフォント・ライブラリの読み込みのみ）。

**Q10. 作物を追加したいときは？**
A. `saitama-data.js` の `crops` に、同じ形式（`id`・`name`・`cropType`・`emoji`・`ecClass`・`basal`・`total`・`compost`・`source`・`page`）で追加してください。`python tests/run_tests.py` でデータの整合性（基肥 ≦ 合計、IDの重複なし等）も確認できます。
